Status: preparation only. No case in this guide is marked executed. Record results against the final integrated SHA in [the verification matrix](v1.5.0-integrated-verification.md). Earlier PR smoke runs do not satisfy these final cases.

## Reproducible environment

Run the final verification ZIP in a dedicated supported IDE with separate config, system, plugins and log directories. Record ZIP hash, source SHA, plugin version, IDE/JBR/OS versions, English UI, default theme and actual viewport. One task owns GUI control; obtain explicit handback from #74 before the coordinator starts. Use disposable demo projects A and B, copied from the committed capture guide/sample. Reset Timeout.kt to 10 before starting. Do not import the user's IDE settings.

Use the official native macOS app launcher with an external IDEA_PROPERTIES file if Gradle's Java Main process is not selectable by CUA. Do not alter the app signature or security protections. The verified local runtime is described in the coordination record; it is a development convenience, not a distributable release artifact.

## Collection and source lifecycle

1. Start a new project session. Open the empty tool window and verify empty guidance, session include-code enabled, and disabled Copy All. Close/hide the panel, select Timeout.kt line 3 and invoke Add. Confirm the editor keeps focus and the panel is not opened automatically.
2. Reopen the panel. Capture another range and a second file. Add a multi-caret batch whose ranges are deliberately created in reverse order; verify stored ranges are top-to-bottom, selections remain separate and current-line fallback/end-boundary handling matches the source.
3. Re-add unchanged text, then switch relative/absolute path preference and re-add. Both are duplicates; the original captured display path remains unchanged. Modify the original selected line without saving and capture again. The old code remains, the new item gets a later fixed number/time, and built-in output labels both versions of the same location.
4. Rename, move and delete a source through IDE actions on the disposable project. Verify textual source states, unchanged captured code/path/output and continued copy availability. Recreate the deleted pathname and verify it does not revive the old source identity. Record live UI wiring here; deterministic event interleavings remain covered separately by platform fixtures.

## Keyboard and content lifetime

Select by keyboard, move up/down, remove, and verify predictable selection/focus and disabled edge moves. Delete in a preview must not remove collection rows. Cancel Clear All, then confirm it and verify the list count. A confirmation whose captured content revision changes must not clear a newer list; use the registered deterministic fixture for the nested-event case and ordinary cancel/confirm in the actual IDE.

Check complete read-only captured and final output text, meaningful accessible names and textual states, narrow-window layout, viewer/action tab reachability, and one noncloseable content tab. Hide/reopen the panel and verify retained session state. At the end close/reopen project A and verify captures are discarded and collection include-code returns to true independently of one-shot settings. Verify no collection snapshots/settings appear in plugin persisted state.

## Output and warning paths

Exercise both built-in formats, custom substitution, whitespace trimming, collection code toggle and one-shot-setting independence. Verify Calculating invalidates old bytes/preview and Copy All availability until the matching result arrives. Check a custom template with blank per-item output is blocked rather than omitting that item. For same-location captures, use a small custom reference-only output and confirm the snapshot/reference reasons appear even below the size threshold; combine them with an above-threshold output and observe one confirmation.

Use `docs/samples/context-collection/generate-warning.py` for the committed warning sample and its exact template instructions. Its one item has 262144 raw bytes and 262145 final bytes. Verify the actual dialog's bytes/count, default Cancel, retained collection after cancellation and successful Copy Anyway. Compare final payload using the read-only prepared output or an unsaved paste observation. An editor save can strip trailing spaces: never report a saved text file as a byte-exact clipboard dump unless that behavior was disabled and verified.

For manual exact boundaries, prepare disposable ASCII fixtures with known byte counts before opening them. A one-line 262144-byte item is allowed and 262145 bytes is rejected. Eight distinct maximum-size items total 2097152 raw bytes; another nonduplicate item must be rejected without changing the collection. A custom template containing 16 consecutive `{code}` substitutions of one maximum-size item yields exactly4194304 final bytes and is allowed after confirmation; adding one ASCII literal exceeds the hard limit and must block. Use the UI's code option consistently and do not assume raw bytes equal output bytes. Record any oversized AX values through bounded summaries instead of sending megabytes of text to the task.

For item count, a disposable file with100 selected equal-length ranges on distinct lines produces100 nonduplicate captures. Verify an additional item and an oversized multi-caret batch are rejected atomically after deduplication. Exact boundary arithmetic, Unicode/malformed UTF-16, overlap and cancellation are independently covered by the final automated suite; record manual evidence separately rather than substituting one for the other.

Confirm existing history and gutter remain unchanged, notification preference is honored and enabled analytics/review accounting occurs once per successful collection copy. Verify ordinary copy, code copy, relative/absolute actions, permalink, history re-copy and status re-copy still work with their existing policies.

With two live demo projects, exercise collection and ordinary/re-copy paths in both directions and verify the most recent request's visible result. Do not claim a deterministic race from an uncontrolled timing experiment.
